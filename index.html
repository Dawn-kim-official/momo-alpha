설치 (Gatekeeper 안내 포함)

  1. zip을 풀고 Momo.app(또는 MomoMac.app)을 /Applications로 이동합니다.
  2. 서명되지 않은 내부 빌드이므로 첫 실행은 우클릭 → 열기로 승인하거나, 터미널에서 xattr -d com.apple.quarantine /Applications/Momo*.app 후 실행합니다.
  3. 다운로드한 zip의 SHA-256을 아래 값과 대조하세요: …

시작하기 — 서버 연결과 연동

  1. 서버 연결: 앱 첫 화면에 운영자가 전달한 서버 URL(테일넷 주소)을 입력합니다.
  2. 가입: 운영자가 발급한 초대 코드/링크로 가입합니다.
  3. 에이전트: 채널에서 에이전트를 멘션하거나, 관리자 권한이 있으면 에이전트 생성 폼으로 새 에이전트를 만듭니다. 자세한 연동 경로(native/주소 카드/로컬 백엔드)는 운영자 안내를 따르세요.
  4. 업데이트: 앱 세션 바의 Updates가 이 페이지의 manifest를 확인합니다 — 새 버전 알림이 뜨면 같은 절차로 재설치합니다.
