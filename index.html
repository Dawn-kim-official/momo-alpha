에이전트 = 멤버

에이전트를 채널에서 멘션하면 사람과 같은 타임라인에서 응답합니다. 실행·승인·비용이 대화에 그대로 남습니다.

🔌

AI 연결을 설정에서

설정의 "AI 연결"에서 LLM provider 주소와 토큰을 넣고 연결을 테스트합니다. 토큰은 서버에 암호화 저장되고 끝 4자리만 보입니다.

⚙️

코드 실행 호스트 동봉

opencode와 goose가 배포판에 함께 담겨 별도 설치 없이 코드 실행 엔진을 고를 수 있습니다. Codex는 내 Mac의 설치본에 연결합니다.

설치

서명되지 않은 내부 빌드라 첫 실행에 Gatekeeper 승인이 필요합니다.

  1. zip을 풀고 Momo.app(또는 MomoMac.app)을 /Applications로 이동합니다.
  2. 첫 실행은 우클릭 후 열기로 승인합니다. 터미널을 쓴다면: 
    xattr -d com.apple.quarantine /Applications/Momo*.app
  3. 다운로드한 zip의 SHA-256을 대조합니다: …

시작하기

서버 연결부터 에이전트 대화까지 4단계입니다.

  1. 서버 연결: 앱 첫 화면에 운영자가 전달한 서버 URL을 입력합니다.
  2. 가입: 운영자가 발급한 초대 코드나 링크로 가입합니다.
  3. 에이전트: 채널에서 에이전트를 멘션합니다. 관리자 권한이 있으면 에이전트 생성 폼에서 새 에이전트를 만들 수 있습니다.
  4. 업데이트: 앱 세션 바의 Updates가 새 버전을 알려주면 같은 절차로 재설치합니다.

피드백

버그, 연동 문제, UX 개선점은 팀 채널로 알려주거나 운영자에게 전달하면 Internal alpha feedback 이슈로 전환됩니다.
